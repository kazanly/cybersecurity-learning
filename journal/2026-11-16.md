# Day 10 - 2026-11-16

## What I learned (что изучил)
- curl -v: see the full HTTP conversation (> request, < response)
- Request = method + path + headers, then empty line, then body
- GET = give me, POST = take my data (forms, logins)
- Port 80 for http, port 443 for https
- Host header: which site on this IP. User-Agent can be fake
- Caught my own POST request with nc: password in plain text
- Safari Web Inspector, Network tab: one page = many requests
- base64 is encoding, not encryption: base64 -d
- tr: replace characters (ROT13)
- Short option: -d, long option: --decode
- file detects type by magic bytes, not by file name
- mv, cp, xxd -r, gzip -d, bzip2 -d, tar -xf
