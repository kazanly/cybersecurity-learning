## What I learned (что изучил)
- HTTPS: TLS handshake (Client hello, Server hello, Certificate, Finished)
- Certificate = passport of a website: subject, issuer, expire date
- Chain of trust: root CA -> intermediate CA -> website
- badssl.com: expired certificate, wrong host name
- Self-signed certificate: encryption yes, identity no
- scp -P: copy files over SSH (big P for port)
- ssh -i key: log in with a private key
- chmod 600: only owner can read and write (r=4, w=2, x=1)
- openssl s_client -connect host:port: TLS client
