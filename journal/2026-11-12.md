## What I learned (что изучил)
- Hidden files start with a dot, use ls -la
- File permissions: owner, group, others
- file command shows file type (data or text)
- * means all files (wildcard)
- Port = service on computer (22 SSH, 53 DNS, 443 HTTPS)
- TCP = with confirmation (phone call), UDP = without (shout)
- Three-way handshake: SYN, SYN-ACK, ACK
- lsof -i shows network connections on my Mac
