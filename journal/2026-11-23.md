# Day 15 - 2026-11-23

## What I learned (что изучил)
- cron: runs commands on a schedule (every minute, at reboot)
- /etc/cron.d/: system cron jobs; crontab -l: user cron jobs
- * * * * * = every minute (minute, hour, day, month, weekday)
- @reboot = at every start
- &> /dev/null: hide all output (normal and errors)
- Shell script (.sh): list of commands, starts with #!/bin/bash
- Misconfiguration: a script copied a password to a world-readable file in /tmp (chmod 644)
- Persistence: cron on Linux, services and Task Scheduler (4698) on Windows
- Windows logon type 10 = RDP
